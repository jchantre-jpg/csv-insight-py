# CSV Insight (Python)

![Python](https://img.shields.io/badge/Python-stdlib-3776AB?logo=python&logoColor=white)
![CSV](https://img.shields.io/badge/data-CSV-green)

CLI de **análisis exploratorio** sobre CSV sin dependencias externas:
detecta columnas numéricas vs categóricas, estadísticas y top valores.

## Uso
```bash
python csv_insight.py sample.csv
```
